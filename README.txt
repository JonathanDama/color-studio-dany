PUBLICAR GRÁTIS NO GITHUB PAGES
1. Criar um repositório no GitHub, por exemplo: color-studio-dany-links
2. Fazer upload de TODOS os ficheiros mantendo a pasta assets.
3. No repositório, ir a Settings > Pages.
4. Em Build and deployment escolher "Deploy from a branch".
5. Branch: main / root e guardar.
6. O GitHub gera um endereço do género:
   https://SEU-UTILIZADOR.github.io/color-studio-dany-links/
7. Colocar esse link no campo "Links" do Instagram.
